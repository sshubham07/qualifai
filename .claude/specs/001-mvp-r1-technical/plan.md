## Key flows
1. `POST /v1/interviews` → PDF→text → `run_intake` (sync) → dedupe by input hash →
   SUBMITTED→PREPARING → enqueue `prepare_interview_job`.
2. Worker: `prepare_kit` (progress → Redis pub/sub → SSE) → kit stored → READY → email.
3. `POST /start`: TimeWindow.for_duration → persist window → schedule `hard_stop_job` at
   hard_end + 60 s → `InterviewService.start` → first question.
4. `POST /answers`: integrity events → `submit_answer` (graph resumes) → next question or end →
   on end enqueue `evaluate_interview_job`.
5. Worker: `evaluate_interview` → report JSON → HTML → email.

## Risks & mitigations
| Risk | Mitigation |
|---|---|
| Small-model judgement | Rubrics pre-generated by large model; seed anchors; evals harness |
| Free-tier quotas | Phases on different models; compact prompts; local live models |
| STT n/a (text) — paste cheating | Integrity events in report |
| Graph change during live interviews | Graph version stored in state; finish old version |
